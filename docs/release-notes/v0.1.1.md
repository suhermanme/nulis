## What's new

- **Open files from Finder (macOS).** Nulis now appears in Finder's **Open With** menu for text, source code, and data files, and you can drop files on its Dock icon. It is offered as an alternative app, so it does not replace the default app for any file type.
- **Files open in the running window.** A file sent to Nulis while it is open — from Open With, the Dock, or the command line — opens as a new tab instead of starting a second copy.
- **Command line.** `nulis-desktop file.txt` opens the file on every platform.

## First launch

These builds are not signed with a paid Apple or Microsoft certificate, so each system asks once.

- **macOS:** open the `.dmg` and drag Nulis into Applications, then open it. When macOS says it could not verify Nulis, click **Done**. Open **System Settings ▸ Privacy & Security**, scroll to **Security**, and click **Open Anyway** next to the message about Nulis; confirm with your password or Touch ID. You do this once per installed version. If Nulis is not in Finder's Open With menu straight away, open the app once and look again.
- **Windows:** if SmartScreen shows *Windows protected your PC*, click **More info**, then **Run anyway**.
- **Linux:** no extra step; the package manager installs the libraries Nulis needs.

## Known limitations

- Builds are not signed with a Developer ID or code-signing certificate, hence the first-launch steps above.
- On Windows and Linux, Nulis does not yet add itself to the system's "Open with" list.
- Linux packages are for 64-bit x86 only.
