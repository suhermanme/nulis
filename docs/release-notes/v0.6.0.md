A right-click menu in the terminal, a grab pointer for moving text, light themes that reach every control, and editor fixes for word wrap, bookmarks and empty lines.

## New

- **Terminal right-click menu** with **Copy**, **Paste**, **Select All** and **Clear**. Paste goes through the terminal's own paste, so shells that ask for bracketed paste get it.
- **A grab pointer while you move text.** Pressing selected text shows a grabbing pointer while you drag it; holding Option (macOS) or Ctrl (Windows and Linux) shows the copy pointer, and outside the editor, where nothing can be dropped, the no-drop pointer.

## Fixed

- **Light themes:** the editor toolbar's dropdowns and buttons, the INS and EDIT controls, the hex toolbar, the find bar, search results, and the macro and script panels stayed dark. They now use the theme's colors.
- **Title bars and dropdown lists follow the theme,** not the system: a light theme on a dark Mac no longer keeps a black title bar, and scrollbars follow too.
- **Terminal selection** was invisible under a light theme. It now uses the theme's selection color, like the editor.
- **Word wrap:** clicking any row of a wrapped line put the caret on its first row, and Up and Down could not reach the other rows. Clicks now land where you click, Up and Down move one visual row, and the last word of a row no longer jumps while you type in it.
- **Empty lines** showed a cut-off caret, for example in a new file before anything was typed.
- **Bookmarks** set at the start of a line showed on the line above as well, and a fold arrow could hide one. A bookmark now shows on one line only, as a ribbon in its own lane at the gutter's edge.
- **The view jumped** when the editor took focus back, for example after toggling a bookmark from the toolbar or closing the Go To bar with Escape.
- **Linux (GNOME on Wayland):** windows could be dragged about 50 px narrower than their minimum, clipping the document map and the end of the toolbar and status bar.
- **Syntax highlighting** keeps its time limit on slow parses with the newer tree-sitter, and dependencies are updated across the board.

## First launch

These builds are not signed with a paid Apple or Microsoft certificate, so each system asks once.

- **macOS:** open the `.dmg` and drag Nulis into Applications, then open it. When macOS says it could not verify Nulis, click **Done**. Open **System Settings ▸ Privacy & Security**, scroll to **Security**, and click **Open Anyway** next to the message about Nulis; confirm with your password or Touch ID. You do this once per installed version.
- **Windows:** if SmartScreen shows *Windows protected your PC*, click **More info**, then **Run anyway**.
- **Linux:** no extra step; the package manager installs the libraries Nulis needs.

## Known limitations

- **Inline `data:` images** in Markdown are not shown in the preview (their alt text is).
- **Export to PDF writes the Markdown source,** in Edit and View mode alike. To get a PDF of the formatted preview, use **Print…** in View mode and save as PDF from the system print dialog (**PDF ▸ Save as PDF** on macOS, **Microsoft Print to PDF** on Windows).
- Builds are not signed with a Developer ID or code-signing certificate, hence the first-launch steps above.
- On Windows and Linux, Nulis does not yet add itself to the system's "Open with" list.
- Linux packages are for 64-bit x86 only.
