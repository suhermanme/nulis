Automatic indentation, suggestions while you type, and better support for the languages Nulis itself is written in.

## Typing

- **Automatic indentation.** **Enter** starts the new line with the right indentation for the language: one level deeper after `{`, a Python `:`, an opening HTML or XML tag, a YAML key, a Makefile rule, or a block keyword such as Ruby `def` or Bash `then`, and Enter between `{}` or `<p></p>` puts the closing part on its own line. A closing bracket or tag typed on an empty line moves into place, and `end`, `fi`, or `End Sub` move left when you press Enter. **Tab** inserts a tab or spaces, following how each file is already indented; **Backspace** removes one level of spaces. **Settings ▸ Editor ▸ Indentation** sets this up, and **Auto-indent: Off** gives the plain line break of earlier versions.
- **Suggestions.** While you type a word, Nulis suggests words from the document, the language's keywords and types, and snippets (`fn`, `def`, `for`, `html5`, …) with placeholders you visit with **Tab**. The list opens by itself in languages with keywords, and with **Ctrl+Space** (or **Option+Esc** on macOS) anywhere. **Settings ▸ Editor ▸ Suggestions** controls it.

## Languages

- **Settings ▸ Languages** can switch Validate, Beautify, Minify, the Markdown preview, automatic indentation, and suggestions off for one language.
- **Your own file associations:** `files.associations` in `settings.json` (for example `"*.h": "cpp"` or `"Jenkinsfile.*": "ruby"`) decides how a kind of file opens. A language chosen with **View As** is remembered across restarts.
- **JavaScript and TypeScript** highlight regular expressions, the code inside `${…}` in template strings, and JSX elements.
- **Folding** for Markdown sections (under each heading) and YAML blocks (by indentation).
- **Go to Matching Bracket** works in Python.
- New languages: **JSON with Comments** (`.jsonc`), **TSX**, and **Ignore File** (`.gitignore`, `.gitattributes`, `.npmignore`, `.dockerignore`, `.prettierignore`, `.eslintignore`).

## Problems

- **Optional language servers.** Nulis can show the problems reported by a language server you already have, such as `rust-analyzer` or `clangd`. Add it to `lsp.servers` in `settings.json` and approve its exact command and languages in **Settings ▸ Languages ▸ Language servers**; nothing runs before that. A server starts when a document of one of its languages opens, runs once per project folder, and stops when the last such document closes. **Revoke** stops it; **Restart** recovers one set aside after repeated failures. Nulis does not bundle or download servers.
- **Problems panel.** Problems appear as a coloured dot in the gutter and a wavy underline under the text. The status bar counts them; click the count to open the panel, where choosing a problem selects it and scrolls it into view.

## Changed

- These files open differently: `.jsonc` as JSON with Comments (was Plain Text); `.tsx` as TSX (was TypeScript); `Dockerfile.*` and `Containerfile.*` as Dockerfile (were Plain Text); `.tsbuildinfo` as JSON (was Plain Text); the ignore files above as Ignore File (were Plain Text). Map any of them back with `files.associations` or **View As**.
- A compiled AppleScript (`.scpt`) opens read-only in the hexadecimal view, like a binary property list, instead of as unreadable text.
- **Toggle Comment** in CSS writes `/* … */`; it used to write `//`, which plain CSS does not accept.
- The native **Tools** menu shows a disabled "Minify" (not "Minify JSON") when the document has no Minify.
