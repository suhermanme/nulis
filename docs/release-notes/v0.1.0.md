The first release of **Nulis**, a desktop editor for text, source code, hexadecimal data, and files larger than memory. *Nulis* is a Javanese word that means "writing".

## Downloads

| System | File | Notes |
| --- | --- | --- |
| macOS (Apple silicon and Intel) | `Nulis_0.1.0_universal.dmg` | One application for every Mac. |
| Windows 10 and 11 (64-bit) | `Nulis_0.1.0_x64-setup.exe` | Installs for the current user; no administrator rights needed. |
| Debian, Ubuntu, and derivatives (64-bit) | `Nulis_0.1.0_amd64.deb` | Install with `sudo apt install ./Nulis_0.1.0_amd64.deb`. |
| Fedora, RHEL, openSUSE, and derivatives (64-bit) | `Nulis-0.1.0-1.x86_64.rpm` | Install with `sudo dnf install ./Nulis-0.1.0-1.x86_64.rpm`. |

`SHA256SUMS.txt` lists the checksum of every file.

## First launch

These builds are not signed with a paid Apple or Microsoft certificate, so each system asks once before the first launch.

- **macOS:** open the `.dmg`, drag Nulis into Applications, and open it. macOS says it cannot verify the app; click **Done**. Then open **System Settings ▸ Privacy & Security** and click **Open Anyway** next to the message about Nulis.
- **Windows:** if SmartScreen shows "Windows protected your PC", click **More info**, then **Run anyway**.
- **Linux:** no extra step. The package manager installs the two libraries Nulis needs (WebKitGTK and GTK).

## What is in it

- Editing for files of any size: a 10 GiB file opens instantly, and only what is on screen is read.
- Safe, atomic saving; undo and redo; crash recovery of unsaved work.
- Multiple carets, column (block) editing, drag-and-drop of selections, bookmarks, folding, and word wrap.
- Line change indicators: red for unsaved lines, green for lines saved during the session.
- Edit and Read-Only modes per document, and a status bar with the caret position and the size in bytes and characters.
- Find and replace with regular expressions, find in files, and Go To line.
- Syntax highlighting for 37 languages, with detection from file names and content.
- JSON and XML tools: validate, beautify, and minify.
- Hexadecimal editor, document and folder comparison, Markdown preview, integrated terminal, and read-only SFTP.
- Tabs that combine into workspaces of split panes; a File View of the whole computer.
- 99 color themes, configurable shortcuts, menus, and toolbar, macros, approved scripts, and JavaScript plugins.
- Built-in help (F1) with a full user guide and a plugin developer guide.

## Known limitations

- Builds are not signed with a Developer ID or code-signing certificate, hence the first-launch steps above.
- Linux packages are for 64-bit x86 only.
- Text encodings are UTF-8 and Windows-1252; there is no automatic encoding detection yet.
- Remote (SFTP) files are read-only.
- XML validation checks that a document is well-formed, not that it matches a DTD or schema.
