Search that keeps up with huge files, colors you can always see, and tools for YAML and property lists.

## Search

- **Count All has no limit.** It counts every match and every line that holds one, even in a file of tens of gigabytes. The status line shows how far it has got, the button becomes **Cancel**, and you can keep working meanwhile. (In 0.2 it stopped at 10,000 matches.)
- **Faster plain-text search.** Searching without regular expressions is about eight times faster on large files, for Find, Count All, Replace, and highlighting.
- **Regular expressions that can never hang.** Patterns such as `\w+`, `a.*b`, and `[0-9]+` now work (0.2 refused them). One familiar syntax, with named groups, Unicode classes, and POSIX classes; lookahead, lookbehind, and backreferences are not supported, and Nulis says so when you use one.
- **Groups in Replace.** `$1`, `${name}`, `$&`, and `\1` put back what the pattern matched, in Replace, Replace All, and Replace in Files.
- **Search in column.** Search each line only between two columns, with `^` and `$` at the column edges.
- **A tidier Find window.** It fits its content on every tab, remembers its options, shows mistakes in a pattern as you type, and has a **?** button that opens the new *Regular expressions* section of Nulis Help. *Highlight all* now shows exactly what Find Next finds.

## Themes

- **The selection is always clearly visible**, and toolbar and side-bar icons and secondary text are readable in every theme. Where a theme's own colors are too faint (many NvChad themes), Nulis strengthens them in that theme's hues.
- Nulis's own themes are now **Nulis · Ember Night** and **Nulis · Paper Current**, at the top of the theme list.

## Files and tools

- **YAML tools.** *Validate YAML* checks every document in the file and catches a key used twice. *Beautify YAML* re-indents; when that would remove comments or expand anchors, it asks first, and it leaves files with tags such as `!Ref` alone.
- **Property list tools.** *Validate plist* checks the structure and the values (`<integer>`, `<real>`, `<date>`, `<data>`); *Beautify plist* re-indents.
- **New highlighting.** CSV and TSV, with each column in its own color (the separator of a `.csv` is taken from its first line). YAML now marks `---`, anchors, aliases, tags, and block text.
- **Binary property lists** open read-only in the hexadecimal editor instead of as unreadable text.
- **Paging through large files** is easier to spot: the *Previous viewport* and *Next viewport* buttons are filled with the theme's accent color.
- Nulis now highlights 40 languages. `Samples/` in the repository has a file for each.

## First launch

These builds are not signed with a paid Apple or Microsoft certificate, so each system asks once.

- **macOS:** open the `.dmg` and drag Nulis into Applications, then open it. When macOS says it could not verify Nulis, click **Done**. Open **System Settings ▸ Privacy & Security**, scroll to **Security**, and click **Open Anyway** next to the message about Nulis; confirm with your password or Touch ID. You do this once per installed version.
- **Windows:** if SmartScreen shows *Windows protected your PC*, click **More info**, then **Run anyway**.
- **Linux:** no extra step; the package manager installs the libraries Nulis needs.

## Known limitations

- Builds are not signed with a Developer ID or code-signing certificate, hence the first-launch steps above.
- On Windows and Linux, Nulis does not yet add itself to the system's "Open with" list.
- Linux packages are for 64-bit x86 only.
- The new features were checked by hand on macOS; on Windows and Linux they are covered by the automated tests.
